แนวโน้มรายวัน (Daily Trend)

จำนวนเที่ยวและน้ำหนักรวมในแต่ละวัน ตามช่วงเวลาที่เลือกในตัวกรอง

จำนวน Shipment ต่อวัน

นับจำนวน Shipment ต่อ 1 วัน ตามวันที่ (Shipment Date) เรียงตามลำดับเวลา — แสดงครบทุกวัน

น้ำหนักรวมต่อวัน (ตัน)

รวมน้ำหนัก (Weight) ของทุก Shipment ในวันนั้นๆ หารด้วย 1,000 เพื่อแปลงเป็นตัน — แสดงครบทุกวัน

แนวโน้มรายสัปดาห์ (Weekly Trend)

จำนวนเที่ยวและน้ำหนักรวม แบ่งเป็นสัปดาห์ (จันทร์-อาทิตย์) เพื่อดูภาพรวมเมื่อมีข้อมูลหลายเดือน

จำนวน Shipment ต่อสัปดาห์

รวมจำนวน Shipment ของทุกวันในสัปดาห์เดียวกัน (เริ่มวันจันทร์) แสดงเป็นช่วงวันที่ของสัปดาห์นั้น

น้ำหนักรวมต่อสัปดาห์ (ตัน)

รวมน้ำหนักของทุก Shipment ในสัปดาห์เดียวกัน หารด้วย 1,000 เพื่อแปลงเป็นตัน

แนวโน้มรายเดือน (Monthly Trend)

จำนวนเที่ยวและน้ำหนักรวม แบ่งเป็นรายเดือน — เห็นภาพรวมระยะยาวเมื่อมีข้อมูลสะสมหลายเดือน

จำนวน Shipment ต่อเดือน

รวมจำนวน Shipment ของทุก Shipment ในเดือนเดียวกัน (ตาม Shipment Date)

น้ำหนักรวมต่อเดือน (ตัน)

รวมน้ำหนักของทุก Shipment ในเดือนเดียวกัน หารด้วย 1,000 เพื่อแปลงเป็นตัน

เวลาที่ใช้ต่อประเภทรถ และ ต่อ Gate

Running Time = Gate Check out − Gate Check in (นาที) เฉลี่ยและสูงสุด

เวลาเฉลี่ย/สูงสุด ต่อประเภทรถ

คำนวณจากช่วงเวลารวมของแต่ละ Shipment (Gate แรกถึง Gate สุดท้าย)

เวลาเฉลี่ย/สูงสุด ต่อ Gate

ใช้ค่า "Running Time (mm)" ที่ระบบต้นทางคำนวณไว้แล้วต่อการเข้า Gate แต่ละครั้ง (ตรวจสอบแล้วว่าตรงกับ Gate Check out − Check in) ไม่ใช่ค่าที่คำนวณเอง

ช่วงเวลาที่รถหนาแน่นที่สุด

จำนวน Shipment แยกตามชั่วโมงที่เข้า Gate ครั้งแรก และชั่วโมงที่ออกจาก Gate สุดท้าย

จำนวนเที่ยวรถตามช่วงเวลา (เข้า)

ชั่วโมงที่มีรถเข้า Gate แรกมากที่สุด — นับจากเวลาเข้า Gate แรกของแต่ละ Shipment

จำนวนเที่ยวรถตามช่วงเวลา (ออก)

ชั่วโมงที่มีรถออกจาก Gate สุดท้ายมากที่สุด — นับจากเวลาออก Gate สุดท้ายของแต่ละ Shipment

การใช้งานยานพาหนะ (Fleet Utilization)

จัดกลุ่มตามตาราง Type: TL / 10W / 12W / 6W / 4W / Pickup / พ่วงแม่-ลูก

จำนวนเที่ยว vs น้ำหนัก แยกตามประเภทรถ

สินค้า (Material Desc) น้ำหนักรวมสูงสุด (Top 12)

รวมน้ำหนักทุกบรรทัดรายการของสินค้าเดียวกัน

สินค้า (Material Desc) เที่ยวรถบ่อยที่สุด (Top 12)

นับจำนวน Shipment ที่มีสินค้านี้ปรากฏ (ไม่นับตามน้ำหนัก)

ลูกค้า (Sold To Name) เที่ยวรถมากที่สุด (Top 10)

นับจำนวน Shipment ต่อลูกค้า (ตัดคำ บริษัท/จำกัด/ห้างหุ้นส่วน ออกแล้ว) — คลิกที่แถวเพื่อดูรายการสินค้าที่ซื้อ และ Gate ที่ผ่าน (% ของเที่ยวลูกค้านั้น)
#ลูกค้าจำนวนเที่ยวน้ำหนักรวม

สัดส่วนลูกค้าแบบ Pareto (80/20)

ลูกค้ากี่รายที่รวมกันสร้างน้ำหนักขนส่ง 80% และมีลูกค้าที่ซื้อครั้งเดียวมากแค่ไหน

อันดับลูกค้าตามน้ำหนักสะสม (Pareto)

เรียงลูกค้าจากน้ำหนักรวมมากไปน้อย แล้วสะสม % ของน้ำหนักทั้งหมดไปเรื่อยๆ — แถวที่แรเงาสีส้มคือกลุ่มลูกค้าที่รวมกันแล้วถึง 80% ของน้ำหนักทั้งหมด (แสดงสูงสุด 20 อันดับแรก)

สินค้าที่มักขึ้นด้วยกันบ่อยๆ & Shipment หนักสุด

คู่ Product Group และคู่ Material Desc ที่ปรากฏร่วมกันบ่อยที่สุด และ 10 อันดับ Shipment น้ำหนักสูงสุด

คู่สินค้าที่ขึ้นด้วยกันบ่อยที่สุด (Top 12)

นับจำนวน Shipment ที่มีสินค้าทั้งสองกลุ่มร่วมกัน (Product Group)

คู่ Material Desc ที่ขึ้นด้วยกันบ่อยที่สุด (Top 12)

นับจำนวน Shipment ที่มีสินค้าทั้งสองรายการนี้ร่วมกัน — เรียงจากบ่อยที่สุด

Top 10 Shipment น้ำหนักสูงสุด

เรียง Shipment ทั้งหมดตามน้ำหนักรวม (Weight) จากมากไปน้อย แสดง 10 อันดับแรก — คลิกที่แถวเพื่อดูไทม์ไลน์เต็ม (ชั่งน้ำหนักเริ่มต้น → Shipment → Center → Gate ทุกจุด → ชั่งน้ำหนักสำเร็จ เรียงตามเวลาจริง) และสินค้าในเที่ยวนั้น เวลาที่ใช้ต่อ Gate (สีส้ม) = Running Time จากระบบต้นทาง เทียบกับค่าเฉลี่ยของ Gate นั้นทั้งระบบ ส่วนเส้นประคั่นระหว่างจุด = ช่องว่างก่อนเข้าจุดถัดไป
#Shipmentลูกค้าประเภทสถานะรถน้ำหนัก (กก.)SKU

Top 10 Shipment ที่มีสินค้าหลากหลายที่สุด (SKU)

เรียง Shipment ทั้งหมดตามจำนวนรายการสินค้า (SKU / Line Item) จากมากไปน้อย แสดง 10 อันดับแรก — คลิกที่แถวเพื่อดูไทม์ไลน์เต็มและรายชื่อสินค้าทั้งหมดในเที่ยวนั้น
#Shipmentลูกค้าประเภทสถานะรถSKUน้ำหนัก (กก.)

เวลารวมทั้งเที่ยว & จุดที่เสียเวลา (Bottleneck Analysis)

Shipment ไหนใช้เวลารวมนานที่สุด และปัจจัยที่อาจเกี่ยวข้อง (จำนวนสินค้า/จำนวน Gate ที่ผ่าน) สัมพันธ์กันจริงหรือไม่

Top 10 Shipment ที่ใช้เวลารวมนานที่สุด

เวลารวม = เวลาตั้งแต่เข้า Gate แรกจนออก Gate สุดท้าย (นาที) — แสดงคู่กับจำนวนรายการสินค้า (SKU) และจำนวน Gate ที่ผ่านในเที่ยวนั้น เพื่อดูว่าเวลาที่มากขึ้นสอดคล้องกับ SKU/Gate ที่มากขึ้นหรือไม่ · คลิกที่แถวเพื่อดูไทม์ไลน์เต็มตั้งแต่ชั่งน้ำหนักเริ่มต้นจนชั่งน้ำหนักสำเร็จ เรียงตามเวลาจริง

เวลารวมสัมพันธ์กับ SKU และ Gate มากแค่ไหน?

ค่าสหสัมพันธ์ (Pearson correlation, r) ระหว่างเวลารวมต่อเที่ยว กับจำนวนรายการสินค้า และจำนวน Gate ที่ผ่าน — คำนวณจาก Shipment ทุกเที่ยวที่มีข้อมูลเวลาครบตามตัวกรองปัจจุบัน ค่า r เข้าใกล้ 1 หรือ -1 คือสัมพันธ์กันมาก เข้าใกล้ 0 คือแทบไม่สัมพันธ์กัน

จุดที่เสียเวลามากที่สุดในกระบวนการ (เฉลี่ยต่อเที่ยว)

รอเข้า Gate = เฉลี่ยจากคอลัมน์ Lost Time เวลาที่รถรอเข้า Gate (ตรวจสอบแล้วว่าคือ "เวลาก่อนเข้า Gate ถัดไปหลังออกจาก Gate นี้" ตรงกับสูตรที่คำนวณเอง 93.1%) ส่วน Shipment Start−Weight Start / Center Process−Shipment Start ใช้ค่าที่ระบบต้นทางคำนวณไว้แล้วโดยตรง (ไม่ได้คำนวณซ้ำ เพราะตรวจสอบสูตรย้อนกลับไม่สำเร็จ) หน่วยเป็นนาที

สรุปเวลาแต่ละช่วง — จุดไหนน่าเป็นห่วง

เฉลี่ย/ต่ำสุด/สูงสุด ของเวลาแต่ละ Gate และ Shipment ที่เวลาผิดปกติทางสถิติ

สรุปเวลาแต่ละ Gate

เฉลี่ย/ต่ำสุด/สูงสุด ของเวลาที่ใช้ที่ Gate นั้น (Running Time) จากทุกครั้งที่มีการเข้า — สถานะเทียบกับค่าเฉลี่ยรวมของทุก Gate: 🔴 น่าเป็นห่วง = เฉลี่ยสูงกว่าค่าเฉลี่ยรวมตั้งแต่ 50% ขึ้นไป · 🟡 เฝ้าระวัง = สูงกว่า 10-50% · 🟢 ปกติ = ไม่เกิน 10%

Shipment ที่เวลาผิดปกติทางสถิติ

Shipment ที่ใช้เวลารวม (Gate แรกถึง Gate สุดท้าย) สูงกว่า "ค่าเฉลี่ย + 2 เท่าของส่วนเบี่ยงเบนมาตรฐาน (SD)" ของ Shipment ทั้งหมดตามตัวกรองปัจจุบัน ถือเป็นค่าผิดปกติทางสถิติ (นอกกลุ่มปกติ ~95% ตามหลัก Normal Distribution) ควรตรวจสอบสาเหตุเป็นพิเศษ — คลิกที่แถวเพื่อดูไทม์ไลน์เต็ม
#Shipmentลูกค้าเวลารวมรถSKUGate

Funnel กระบวนการทำงาน (Process Funnel)

ดูว่า Shipment หลุด/ค้างอยู่ที่ขั้นไหนมากที่สุด ตั้งแต่ชั่งน้ำหนักเริ่มต้นจนออก Gate

Shipment ผ่านแต่ละขั้นตอนกี่เที่ยว

นับจำนวน Shipment ที่มีข้อมูลบันทึกไว้ในแต่ละสเตจ (Weight Start → Shipment Time → Center Time → Weight Success → Gate Check out) เทียบกับจำนวน Shipment ทั้งหมดตามตัวกรองปัจจุบัน — ขั้นไหนที่จำนวนหล่นเยอะ แปลว่าเที่ยวรถจำนวนมากไม่ถูกบันทึกข้อมูล ณ ขั้นนั้น ควรตรวจสอบกระบวนการหน้างาน

เที่ยวรถที่ส่งหลายปลายทาง (Multi-Destination Delivery)

1 Shipment อาจมีสินค้าหลายรายการที่ต้องส่งคนละปลายทาง (Ship To Name ต่างกัน) — วิเคราะห์ว่ามีกี่เที่ยวที่เป็นแบบนี้ และเที่ยวไหนส่งหลายปลายทางที่สุด

จำนวนปลายทางต่อ 1 Shipment

นับจำนวน Ship To Name ที่แตกต่างกันในแต่ละ Shipment (1 ปลายทาง = ส่งที่เดียว, 2+ = ส่งหลายจุดในเที่ยวเดียว)

Top 10 Shipment ที่ส่งหลายปลายทางที่สุด

เรียงจากจำนวน Ship To Name ที่แตกต่างกันมากที่สุดในเที่ยวเดียว

ปัญหาที่พบ แยกตาม Gate และประเภทรถ (Issue Cross-tab)

Gate หรือประเภทรถไหนที่มีสัดส่วน Shipment ที่มีปัญหา (Issue) สูงที่สุด

อัตราการเกิดปัญหา แยกตาม Gate

% ของ Shipment ที่ผ่าน Gate นั้นแล้วมีหมายเหตุปัญหา (Shipment ที่ผ่านหลาย Gate จะถูกนับในทุก Gate ที่ผ่าน) — วงเล็บคือ จำนวนที่มีปัญหา/จำนวนที่ผ่าน Gate นั้นทั้งหมด

อัตราการเกิดปัญหา แยกตามประเภทรถ

% ของ Shipment แต่ละประเภทรถที่มีหมายเหตุปัญหา — วงเล็บคือ จำนวนที่มีปัญหา/จำนวนเที่ยวทั้งหมดของประเภทรถนั้น

งาน Urgent เทียบกับงานปกติ

เปรียบเทียบเวลารวม น้ำหนักเฉลี่ย และอัตราปัญหา เพื่อดูว่างานด่วนถูกจัดการเร็วกว่าจริงหรือไม่

ตารางเปรียบเทียบ Urgent vs ปกติ

"เวลารวมเฉลี่ยต่อเที่ยว" คำนวณจาก Gate แรกถึง Gate สุดท้าย (span) เฉพาะเที่ยวที่มีข้อมูล Gate ครบ ส่วน "อัตรามีปัญหา" คือ % ของเที่ยวที่มีหมายเหตุปัญหา (Issue) ต่อจำนวนเที่ยวในกลุ่มนั้น

งานคืนสินค้า (Return)

ภาพรวมเที่ยวที่มีประเภทงานเป็น Return ลูกค้าที่คืนบ่อยที่สุด และสินค้าที่ถูกคืนมากที่สุด

ลูกค้าที่มีเที่ยว Return มากที่สุด (Top 10)

นับจำนวนเที่ยว Return ต่อลูกค้า (Sold To Name ตัดคำนำหน้าแล้ว)

สินค้าที่ถูกคืนมากที่สุด ตามน้ำหนัก (Top 10)

รวมน้ำหนักของสินค้าแต่ละชนิดในทุกเที่ยว Return

ปลายทางที่ส่งบ่อยที่สุด (Top Ship-To)

จัดอันดับปลายทาง (Ship To Name) จากทุก Shipment/รายการสินค้า ไม่ใช่แค่เที่ยวที่ส่งหลายปลายทาง

Top 10 ปลายทางที่มีเที่ยวส่งมากที่สุด

นับจำนวน Shipment ที่แตกต่างกันที่ส่งไปยังปลายทางนั้น (Ship To Name ตัดคำนำหน้าแล้ว)

การกระจายน้ำหนักต่อเที่ยว (Weight Distribution)

สัดส่วนเที่ยวรถแยกตามช่วงน้ำหนักสินค้า เพื่อดูภาพรวมขนาดงานที่พบบ่อย

จำนวนเที่ยวแยกตามช่วงน้ำหนัก

แบ่งช่วงน้ำหนักต่อ 1 Shipment เป็น 6 ช่วง ตั้งแต่ต่ำกว่า 1 ตัน ถึง 20 ตันขึ้นไป

ประเภทงาน x ประเภทรถ (Job Type x Vehicle Type)

ดูว่าประเภทรถแบบไหนถูกใช้กับงาน Inbound / Outbound / Return มากที่สุด

ตารางไขว้ ประเภทรถ x ประเภทงาน

นับจำนวนเที่ยวของแต่ละประเภทรถ แยกตามประเภทงาน

แนวโน้มตามวันในสัปดาห์ (Day of Week)

รวมจำนวนเที่ยวและน้ำหนักของทุกวันในสัปดาห์เดียวกัน (เช่น จันทร์ทั้งหมดรวมกัน) — ⚠️ ข้อมูลตัวอย่างมีเพียง ~11 วัน แต่ละวันในสัปดาห์จึงถูกนับแค่ 1-2 ครั้งเท่านั้น ผลลัพธ์เป็นเพียงแนวโน้มเบื้องต้น ยังสรุปแน่ชัดไม่ได้จนกว่าจะมีข้อมูลหลายสัปดาห์ขึ้นไป

จำนวนเที่ยวรวม แยกตามวันในสัปดาห์

รวมทุก Shipment ที่ตรงกับวันนั้นๆ ในสัปดาห์ (จันทร์-อาทิตย์) ตามช่วงเวลาที่เลือกในตัวกรอง

ข้อเสนอแนะเชิงปฏิบัติการ
