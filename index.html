#Shipmentประเภทสถานะรถน้ำหนัก (กก.)SKU

เวลารวมทั้งเที่ยว & จุดที่เสียเวลา (Bottleneck Analysis)

Shipment ไหนใช้เวลารวมนานที่สุด และปัจจัยที่อาจเกี่ยวข้อง (จำนวนสินค้า/จำนวน Gate ที่ผ่าน) สัมพันธ์กันจริงหรือไม่

Top 10 Shipment ที่ใช้เวลารวมนานที่สุด

เวลารวม = เวลาตั้งแต่เข้า Gate แรกจนออก Gate สุดท้าย (นาที) — แสดงคู่กับจำนวนรายการสินค้า (SKU) และจำนวน Gate ที่ผ่านในเที่ยวนั้น เพื่อดูว่าเวลาที่มากขึ้นสอดคล้องกับ SKU/Gate ที่มากขึ้นหรือไม่ · คลิกที่แถวเพื่อดูไทม์ไลน์เต็มตั้งแต่ชั่งน้ำหนักเริ่มต้นจนชั่งน้ำหนักสำเร็จ เรียงตามเวลาจริง

เวลารวมสัมพันธ์กับ SKU และ Gate มากแค่ไหน?

ค่าสหสัมพันธ์ (Pearson correlation, r) ระหว่างเวลารวมต่อเที่ยว กับจำนวนรายการสินค้า และจำนวน Gate ที่ผ่าน — คำนวณจาก Shipment ทุกเที่ยวที่มีข้อมูลเวลาครบตามตัวกรองปัจจุบัน ค่า r เข้าใกล้ 1 หรือ -1 คือสัมพันธ์กันมาก เข้าใกล้ 0 คือแทบไม่สัมพันธ์กัน

จุดที่เสียเวลามากที่สุดในกระบวนการ (เฉลี่ยต่อเที่ยว)

รอเข้า Gate = เฉลี่ยจากคอลัมน์ Lost Time เวลาที่รถรอเข้า Gate (ตรวจสอบแล้วว่าคือ "เวลาก่อนเข้า Gate ถัดไปหลังออกจาก Gate นี้" ตรงกับสูตรที่คำนวณเอง 93.1%) ส่วน Shipment Start−Weight Start / Center Process−Shipment Start ใช้ค่าที่ระบบต้นทางคำนวณไว้แล้วโดยตรง (ไม่ได้คำนวณซ้ำ เพราะตรวจสอบสูตรย้อนกลับไม่สำเร็จ) หน่วยเป็นนาที

Funnel กระบวนการทำงาน (Process Funnel)

ดูว่า Shipment หลุด/ค้างอยู่ที่ขั้นไหนมากที่สุด ตั้งแต่ชั่งน้ำหนักเริ่มต้นจนออก Gate

Shipment ผ่านแต่ละขั้นตอนกี่เที่ยว

นับจำนวน Shipment ที่มีข้อมูลบันทึกไว้ในแต่ละสเตจ (Weight Start → Shipment Time → Center Time → Weight Success → Gate Check out) เทียบกับจำนวน Shipment ทั้งหมดตามตัวกรองปัจจุบัน — ขั้นไหนที่จำนวนหล่นเยอะ แปลว่าเที่ยวรถจำนวนมากไม่ถูกบันทึกข้อมูล ณ ขั้นนั้น ควรตรวจสอบกระบวนการหน้างาน

เที่ยวรถที่ส่งหลายปลายทาง (Multi-Destination Delivery)

1 Shipment อาจมีสินค้าหลายรายการที่ต้องส่งคนละปลายทาง (Ship To Name ต่างกัน) — วิเคราะห์ว่ามีกี่เที่ยวที่เป็นแบบนี้ และเที่ยวไหนส่งหลายปลายทางที่สุด

จำนวนปลายทางต่อ 1 Shipment

นับจำนวน Ship To Name ที่แตกต่างกันในแต่ละ Shipment (1 ปลายทาง = ส่งที่เดียว, 2+ = ส่งหลายจุดในเที่ยวเดียว)

Top 10 Shipment ที่ส่งหลายปลายทางที่สุด

เรียงจากจำนวน Ship To Name ที่แตกต่างกันมากที่สุดในเที่ยวเดียว

ปัญหาที่พบ แยกตาม Gate และประเภทรถ (Issue Cross-tab)

Gate หรือประเภทรถไหนที่มีสัดส่วน Shipment ที่มีปัญหา (Issue) สูงที่สุด

อัตราการเกิดปัญหา แยกตาม Gate

% ของ Shipment ที่ผ่าน Gate นั้นแล้วมีหมายเหตุปัญหา (Shipment ที่ผ่านหลาย Gate จะถูกนับในทุก Gate ที่ผ่าน) — วงเล็บคือ จำนวนที่มีปัญหา/จำนวนที่ผ่าน Gate นั้นทั้งหมด
